# 贺俊兰的前端成长笔记

这是一个基于 `VuePress` 搭建的个人技术博客，用来记录前端学习、项目实践和问题复盘。内容聚焦 `Vue`、`JavaScript`、`Node`、工程化与算法练习，希望把零散经验整理成一份可以持续查阅的知识地图。

## 内容方向

- `Vue`：记录框架基础、响应式原理、路由、服务端渲染、组件库搭建和项目优化经验。
- `JavaScript`：整理基础类型、精度问题、防抖节流、常用技巧与日常排查思路。
- `Node`：沉淀命令行交互、脚本工具、模板生成和自动化实践。
- `算法`：按题型记录解题思路，保留关键步骤和可复用实现。
- `工程实践`：归档侧边栏生成、时间轴实现、路由问题处理等博客搭建经验。

## 项目结构

```text
docs
├── .vuepress      # VuePress 配置、主题和静态资源
├── document       # 技术文章目录
└── README.md      # 博客首页配置
```

## 本地启动

```bash
npm install
sudo npm run dev
```

`macOS` 系统下如果启动权限报错，可以按原项目说明使用 `sudo` 启动。

## 常用命令

```bash
npm run dev
npm run build
```

## 写作原则

每篇文章尽量围绕“问题是什么、为什么会这样、下次怎么更快解决”展开。持续记录，也持续修正，让这份博客既能保存学习轨迹，也能服务后续实践。
