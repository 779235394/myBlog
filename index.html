# 关于这个博客

这里是贺俊兰的前端学习与实践记录，主要整理 Vue、JavaScript、Node、工程化与算法相关内容。每篇文章都尽量从实际问题出发，把概念、代码片段和排查过程沉淀下来，方便复盘，也方便下次遇到同类问题时快速定位。

# 内容方向

  • Vue：记录框架原理、组件实践、路由、状态管理和项目搭建经验。
  • JavaScript：梳理基础类型、精度问题、防抖节流与常用编码技巧。
  • Node：沉淀脚本工具、命令行交互和自动化生成文件的实践。
  • 算法：按题型记录解题思路，保留关键步骤和可复用的实现方式。

# 写作原则

文章会优先回答三个问题：这个问题是什么、为什么会这样、下次怎么更快解决。希望这里不只是零散笔记，而是一份持续生长的前端知识地图。
